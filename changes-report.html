Change report

Azure Variables Refactor

Summary of the current worktree changes. Generated November 20, 2026.

The variable-group feature is being reorganized into domain, application, and adapter modules. Existing state and CLI entry points are updated to use the new module locations.

At a glance

  • Added domain models for variable entries/groups and UI status/theme types.
  • Added application ports for fetching variable groups, clipboard operations, and exporting.
  • Moved Azure DevOps API access, system clipboard handling, and JSON file export into adapters.
  • Updated StateStore to use the exporter port while keeping JSON export as its default.
  • Updated module exports and the CLI imports; adjusted Cargo dependencies and crate feature declarations.

Architecture changes

  • src/azure_vars/domain/models.rs now defines VarEntry, VarGroup, Theme, StatusKind, and StatusMessage.
  • src/azure_vars/application/ports.rs defines the client, clipboard, and exporter interfaces used by application logic.
  • src/azure_vars/adapters/azure.rs implements retrieval and conversion of Azure DevOps variable groups.
  • src/azure_vars/adapters/clipboard.rs contains the system clipboard implementation, including its asynchronous/blocking-work handling.
  • src/azure_vars/adapters/filesystem.rs writes variable groups as formatted JSON and masks secret values in the exported document.

Notable existing-file updates

  • src/azure_vars/state/state.rs removes the inline model definitions and re-exports those types from the domain module.
  • src/azure_vars/state/state_store.rs removes embedded Azure/clipboard implementations in favor of adapter re-exports, and delegates group export to VariableGroupExporter. Export tests were updated for the JSON document shape.
  • src/bin/azure_variables.rs imports the Azure client from its new adapter module.
  • Cargo.toml moves mockall to dev-dependencies, removes dependencies no longer used by the edited code, and Cargo.lock changes accordingly.
  • src/lib.rs removes three crate feature declarations; the existing test feature declaration remains.

Behavior and verification

The intended user-facing behavior remains the same: groups can be loaded, variables can be copied, and the selected group can be exported to JSON. Secret values are masked in exports.

This report summarizes the current workspace diff, including untracked new module files. It does not claim that a build or test suite has been run.
